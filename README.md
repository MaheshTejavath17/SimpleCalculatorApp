# Simple Calculator App (Java + XML)

A beginner-friendly Android calculator built with Java and XML layouts.

## Features
- Addition, subtraction, multiplication and division
- Decimal and negative number input
- Empty/invalid input handling
- Division-by-zero protection
- Clear button and clean layout

## Requirements
- Android Studio
- Android SDK 35 (Android Studio can install it when prompted)
- JDK 17 (use Android Studio's embedded JDK)

## Run the project
1. Extract `SimpleCalculatorApp.zip`.
2. Open Android Studio.
3. Select **Open** and choose the extracted `SimpleCalculatorApp` folder (the folder containing `settings.gradle`).
4. Wait for Gradle sync to finish. If Android Studio asks to install Android SDK 35, accept.
5. Create an Android emulator using **Device Manager**, or connect an Android phone with USB debugging enabled.
6. Select the device and click the green **Run ▶** button.

No API key or internet permission is required by the app.
